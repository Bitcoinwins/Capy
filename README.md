# Quantic Capybara: Star Raider
A standalone mobile-friendly HTML5 side-scrolling space shooter prototype.

## Play
Open `index.html` in a modern browser. It requires no external assets or libraries.
- Desktop: arrow keys or WASD to move; Space to fire.
- Mobile: on-screen direction buttons and Hold Fire.

## Publish free with GitHub Pages
1. Create a public GitHub repository named `quantic-capybara-star-raider`.
2. Upload `index.html` to the repository root and commit it.
3. Go to Settings → Pages.
4. Under Build and deployment choose Deploy from a branch, branch `main`, folder `/(root)`, then Save.
5. Open the published URL GitHub displays after deployment.

Original canvas-drawn graphics and code. Inspired by the broad genre of classic side-scrolling space shooters; no ROM, original Gradius assets, or copyrighted game code included.


**Important:** Keep `capybara-pilot.png` in the same folder as `index.html` when uploading to your host. It is the actual capybara character artwork used in the menu and gameplay.
